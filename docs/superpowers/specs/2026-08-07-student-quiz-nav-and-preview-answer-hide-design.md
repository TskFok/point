# 学生端答题导航同行与预习提交后揭晓

**日期：** 2026-08-07  
**状态：** 已确认  
**背景：** 学生端「上一题」「提交答案」「下一题」分散在两行；预习流程先展示题解再作答。用户要求三钮同一行，且预习答案默认隐藏、提交后才显示（方案 1）。

## 决策摘要

| 项 | 选择 |
|----|------|
| 按钮布局范围 | 练习（`FIRST`）与预习答题页都改 |
| 按钮顺序 | `上一题` · `提交答案` · `下一题` |
| 预习流程 | 取消「先看题解」浏览阶段；抽题后直接作答 |
| 答案揭晓 | 提交后通过现有 `AnswerFeedback` 展示 |
| API | 不改；前端提交前不渲染预习题的正确项/题解字段 |

## 非目标

- 不改答题 API、积分发放、幂等提交逻辑
- 不改错题重练（`WRONG_RETRY`）的无翻题栏交互（仍为单提交按钮）
- 不强制从预习 API 响应中删除 `correctOptionId` / `explanation`（仅 UI 不提前展示）
- 不重做练习/预习视觉主题，仅调整导航布局与预习阶段

## 交互流程

### 预习 `/learn/preview`

1. 选数量 →「开始预习」→ 直接进入答题（`setup → quiz → summary`）
2. 提交前：可选选项；**不展示**正确答案、题解，不预勾选正确项
3. 提交后：`AnswerFeedback` 展示对错、正确答案（错时）、解析、积分（与练习一致）
4. 全部完成后：「查看本次成绩」→ 总结页

### 练习 `/learn`（`mode === "FIRST"`）

- 提交闸门、取题、队尾逻辑不变
- 仅将三钮收进同一导航行

### 按钮行行为

| 状态 | 上一题 | 提交答案 | 下一题 / 末题 CTA |
|------|--------|----------|-------------------|
| 未选题 | 按索引启用 | 禁用 | 预习：禁用至本题已提交；练习：按现有规则 |
| 已选题未提交 | 按索引启用 | 启用 | 同上 |
| 提交中 | 按索引启用 | 禁用（文案「正在提交」） | 同上 |
| 已提交 | 按索引启用 | 从行内移除（或不可点占位，三列不塌） | 预习启用下一题；末题为「查看本次成绩」 |
| 有 submitError | 按索引启用 | 主行可不显示；错误区保留「重试提交」 | 按现有闸门 |

反馈区（`AnswerFeedback` / 错误提示）放在题目卡片与按钮行之间。

## 组件与文案

### `practice-session.tsx`

- `mode === "FIRST"` 的 `practice-navigation` 内顺序：上一题 → 提交答案 → 下一题
- 已有 `result` 时不在导航内渲染提交按钮
- `WRONG_RETRY`：保持现有单提交，不新增翻题

### `preview-session.tsx`

- 删除 `phase === "preview"` 浏览 UI（含 `preview-explanation`、正确项预勾选、「完成预习，开始答题」）
- `getPreviewQuestions` 成功后 `setPhase("quiz")`；`Phase` 可去掉 `"preview"`
- quiz 导航改为三钮同行；末题右侧仍为「查看本次成绩」（需全部答完/跳过）
- 设置页文案改为强调「作答后查看解析并获积分」，去掉「先看题解」表述

### `globals.css`

- `.practice-navigation` 支持三钮同行（flex / 等分布局；中间提交不抢满宽）
- 小屏优先同排（缩小 padding / `min-width: 0`）；过窄允许折行
- 清理仅服务预习浏览的 `.preview-explanation*`（无其它引用时）

## 测试

### 单元

- `preview-session.test.tsx`
  - 开始预习后进入答题；提交前无「正确答案」/题解可见
  - 提交后出现 `AnswerFeedback` 相关文案
  - 不再出现「完成预习，开始答题」及预习浏览进度文案（如「题解已展示」）
  - 三钮同属答题导航；闸门与总结用例同步去掉 preview 阶段步骤
- `practice-session.test.tsx`
  - 断言上一题、提交答案、下一题同属一个导航区域
  - 提交前后行为回归仍通过

### E2E

- `preview.spec.ts`：侧栏进预习 → 抽题后直接作答 → 提交见反馈 → 完成总结
- 其它依赖旧「先看题解」步骤的 Playwright 用例一并更新

## 验收标准

1. 练习与预习答题页按钮为同一行：`上一题 | 提交答案 | 下一题`
2. 预习开始后看不到正确答案/题解；提交后才看到
3. 预习不再出现「完成预习，开始答题」或先看题解浏览阶段
4. 提交闸门、积分、总结与相关单测 / E2E 通过

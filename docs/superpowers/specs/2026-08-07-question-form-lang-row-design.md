# 题目表单：基础积分与语言各占一行

**日期：** 2026-08-07  
**状态：** 已确认  

## 目标

在添加/编辑题目弹窗中，「语言」与「基础积分」各自占用整行，不再并排半宽显示。

## 非目标

- 不改语言字段的选项、校验或提交逻辑
- 不改 `admin-form__grid` 的列数或其它表单字段布局
- 不改 AI 任务表单或其它页面的语言字段布局
- 不新增 CSS 类或全局样式规则

## 决策摘要

| 项 | 选择 |
|----|------|
| 范围 | `QuestionForm`（添加/编辑共用） |
| 布局 | 基础积分整行 + 语言整行（方案 B） |
| 实现 | 复用现有 `admin-field--wide` |

## 布局顺序

`admin-form__grid` 内字段顺序保持不变，仅加宽两列：

1. 题干（整行，已有）
2. 题目解析（整行，已有）
3. 基础积分（改为整行）
4. 语言（改为整行）
5. 启用题目（整行，已有）

## 改动面

- `apps/web/components/admin/question-form.tsx`：给「基础积分」「语言」的 `label` 增加 `admin-field--wide`
- `apps/web/tests/admin-question-form.test.tsx`：新增断言，确认两字段 `label` 含 `admin-field--wide`（对齐现有「启用题目选项占据单独一行」用例）

## 测试

- 单元测试断言「基础积分」「语言」各自 `closest("label")` 带 `admin-field--wide`
- 既有创建/编辑/语言提交相关用例须继续通过
